# Code Review Agent

AI-powered code review agent with multi-platform IM integration.

## Features

- AI-powered code review (Claude / OpenAI / DeepSeek / Ollama)
- Static rule engine for pattern-based checks
- GitHub & GitLab PR integration
- IM bidirectional interaction (Feishu / DingTalk / WeCom / Slack)
- Dynamic webhook output dispatch
- Multi-model LLM layer with fallback chains
